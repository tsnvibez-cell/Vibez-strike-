# Vibez-strike-
Build a secure Node.js and Express.js backend for a multiplayer FPS game called VIBEZ STRIKE.  Features:  1. Player registration and login. 2. Secure password hashing. 3. Player profiles with unique IDs, usernames, levels and XP. 4. Secure authentication sessions. 5. PostgreSQL database integration. 6. REST API endpoints for registration, login, .
